## What it does
The Mechatronics Quiz App is a Python-based interactive quiz designed to test basic knowledge of Mechatronics Engineering.

The application presents multiple-choice questions, checks answers automatically, calculates the final score and percentage, and provides feedback based on performance.

## How to run it
1. Install Python 3.
2. Download the Python file.
3. Open your terminal or Python IDE.
4. Run the following command:

python akharayi_mechatronics_quiz.py

## My own twist

I added a revision feature that displays questions answered incorrectly, provides the correct answers and gives explanations to help users learn from their mistakes.

I also included randomized questions to make each attempt different.
